## Data Availability

The CT imaging data analysed in this study were obtained from public third-party
resources and are not redistributed in the accompanying code repository.
PANORAMA imaging data should be obtained from the original PANORAMA Zenodo
records (batch 1 v3: https://doi.org/10.5281/zenodo.13715870; batch 2 v2:
https://doi.org/10.5281/zenodo.13742336; batch 3:
https://doi.org/10.5281/zenodo.11034011; batch 4 v1.0:
https://doi.org/10.5281/zenodo.10999754). PANORAMA annotations and clinical
metadata were obtained from the official DIAGNijmegen/panorama_labels
repository at commit bf1d6ba3. The source-separated held-out cohorts include
data originating from the Medical Segmentation Decathlon and the NIH
Pancreas-CT collection (https://doi.org/10.7937/K9/TCIA.2016.tNB1kqBU).
Study-generated split manifests, audit records, frozen prediction manifests,
selected checkpoints, and reproducibility metadata are provided with the
archived code release at [ZENODO DOI TO BE ADDED].

## Code Availability

The study-generated code and reproducibility assets for “Compact
Self-Supervised 3D Deep Learning for CT-Based Pancreatic Lesion Detection and
Segmentation” are available from the GitHub repository
https://github.com/zaidsawaff/pdac-compact-3d-ssl and will be archived as the
versioned release [v1.0.0] at [ZENODO DOI TO BE ADDED]. The repository includes
the final analysis/training scripts, environment specification, locked
metadata and audit records, prediction-freeze manifests, selected model
checkpoints, and SHA-256 integrity checks. Raw CT volumes and source masks are
not redistributed. Licence: MIT. Execution instructions are
provided in the repository README and ENVIRONMENT.md.
